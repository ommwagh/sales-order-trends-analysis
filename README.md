# Sales & Order Trends Analysis

## 📊 Overview
This project analyses a year’s worth of sales and order data to identify seasonal trends, top-performing products, and revenue fluctuations. It was built to simulate a real-world sales dashboard and explore the relationship between products, revenue, and time.

## 🔧 Tools Used
- Microsoft Excel (PivotTables, Charts, Conditional Formatting)
- SQL (for query-based replication of insights)

## 📌 Key Insights
- Revenue peaked in **May 2024** and **March 2025**, with clear seasonal spikes.
- Gift sets outperformed individual items, with **Flower & Chocolate** leading in sales.
- Products like **Sunflowers** showed high efficiency (high sales, low waste).
- **Plant & Mug** had high waste but low revenue — a potential area for review.

## 📁 Files Included
- `sales_project.xlsx` – Excel-based analysis with PivotTables and visualizations
- `sales_analysis_queries.sql` – SQL queries replicating core analysis (top products, revenue by month/category, customer trends)

## 🧠 Skills Demonstrated
- Data aggregation and trend analysis
- Product performance evaluation
- Visual storytelling using charts and PivotTables
- SQL: Grouping, filtering, date functions, customer-level metrics
